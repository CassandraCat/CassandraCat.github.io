TEAMCRAFT · v0.1 · 2026-05-28

团队 AI 工作流 — 跨工具打磨的手艺，不是单点工具堆。

跟 superpowers 形成对偶：superpowers 是「一个人怎么变强」×teamcraft 是「一群人怎么变协调」。

Core 规范单源维护 — 工具无关 source 抽到 skills/<skill>/source.md，每个 host (Claude Code · Cursor · Codex) 一份薄壳 adapter 派生。改规范改单源，adapter 自动跟随。

"craft" 不是 "force" — 不装备武器，打磨一套手艺让大家共同用顺。
