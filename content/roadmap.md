## 为什么是 v6

之前的 v5 是「三线并行 (AI / CG / Algo) · 9 个月 · 1260h」, 单 AI 主线。

v6 几个核心调整:

- **从单线变双轨**: AI 拆成 Java 主线 + Python 副线, 主目标精确化为「全栈 + AI 应用工程师」
- **项目锚换了**: 主线锚项目从「BIM 代码生成助手」换成「AI Browser Agent」(更亮眼, Java 阵营空白, 简历金标)
- **副线两个串行**: Obsidian RAG (我自己 Wiki + AI) → AI Code Reader (GitHub repo → 代码地图), 不并行
- **CG 降级**: 6-9 月 1h/天, 10 月 0.5h/天, 11-12 月暂停 (兴趣不丢, 但优先级低于双轨)
- **不写求职动作**: 学习导向, 项目导向 —— 评判标准是「12 月底 GitHub 上有几个能拿出手的作品」
